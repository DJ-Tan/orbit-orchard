# ux-designer (excerpt)

Source: https://github.com/szilu/ux-designer-skill (SKILL.md). License: MIT. Excerpted 2026-09-28.

- Body text ≥16px, line height 1.4–1.6, 50–75 characters per line.
- Contrast 4.5:1 for text, 3:1 for large text, UI boundaries, focus rings and icons.
- Feedback within 100ms feels instant; transitions 150–300ms, ≤500ms for large spatial motion.
- Touch targets: minimum 24×24 CSS px, 44pt/48dp recommended. Focus always visible, never hidden by sticky UI.
- Navigation: current location always visible; desktop ~5–7 top-level items; mobile bottom bar.
- One dominant element per screen.
- Notifications: blocking → modal; success/info → toast with 4–8s auto-dismiss; background event → badge.
- Modal for quick confirmation or 1–3 fields; full page for complex content.
- Design every state: empty, loading, error, overflow.
